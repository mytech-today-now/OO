O&O ShutUp10 profile review intake

Record an owner-reviewed profile from the exact exported .cfg, its O&O source review, and a two-account disposable-VM scope check for every setting and reviewed release.

Review boundary

This page does not choose settings, infer their meaning or scope, authenticate evidence, or approve a profile. Enter only decisions verified by the owner and current O&O sources. The generated JSON is an intake bundle containing the exact profile bytes, a schema version 4 manifest object, and the supplied evidence. It still needs human review and must be split into the installer's separate files and scope records before use.

All processing stays in this browser tab. The uploaded configuration and evidence are embedded in the saved JSON, so store that file as carefully as the profile itself.

1

Profile and owner review

The setting IDs and states are read from the selected O&O export. Other values must come from review evidence.

Select the exact exported .cfg to load its settings.
2

O&O version review

The range is inclusive and uses the executable's four-part Windows FileVersion. Exact-release approval uses the same value for both ends.

For an exact range, the minimum and maximum are recorded automatically. For a wider range, list each reviewed release version and confirm that the list covers every release in the inclusive range.

3

Review every setting

For each ID, enter its verified category, effect, availability, scope, and one complete VM record per reviewed release. Scope evidence must cover the machine hive and both disposable user hives.

Load a valid .cfg file to build the setting review forms.
4

Owner review attestations

These statements are required before an intake bundle can be saved.

To put the JSON beside this HTML page, choose the folder containing this page when the browser asks. Browsers do not let a local page discover or write to its own folder without that choice.

The installable package still requires the separate ooshutup10.cfg, matching ooshutup10.approval.json, and one reviewed profiles/scope-evidence/<SETTING-ID>.md record per setting. Current-user settings are not eligible for this repository's LocalSystem scheduled task.
